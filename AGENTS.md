# Boiling the ocean deck

Reveal.js talk for Claude Community Amsterdam. Run with `bun serve.ts`.

- `deck.js`: slide content and public closed-caption narration
- `style.css`: deck layouts and Anthropic-inspired visual system
- `ocean.js`: persistent WebGL background and scene transitions
- `boil-15min-outline.md`: talk structure
- `boil-15min-slides.md`: detailed slide plan

Closed captions must make deck understandable without presenter. Keep private delivery cues out of captions. Preserve `prefers-reduced-motion` fallbacks.
